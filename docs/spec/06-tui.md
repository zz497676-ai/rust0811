# 06 — 终端界面(TUI)

`cube3-tui` 提供二进制 `cube3`。基于 `ratatui` + `crossterm`。

```
crates/cube3-tui/src/
  main.rs        // 参数解析、终端初始化/还原、事件循环
  app.rs         // App 状态机(模式、光标、选区、剪贴板、撤销栈)
  input.rs       // 按键 -> Action 的映射
  action.rs      // Action 枚举 + 应用 Action 到 App
  command.rs     // 命令行解析与执行
  ui/
    mod.rs       // 整体布局
    tabs.rs      // 层标签条
    grid.rs      // 主网格
    depth.rs     // 深度视图
    status.rs    // 地址框 / 公式栏 / 状态栏
    help.rs      // 帮助浮层
```

命令行用法:

```
cube3 [文件]              # 打开 .c3;省略则新建空工作簿
cube3 --import <a.xlsx>   # 直接导入 xlsx 并进入界面
```

## 6.1 布局

```
┌──────────────────────────────────────────────────────────────┐
│ ‹ 2024-01 │ 2024-02 │[2024-03]│ 2024-04 │ … ›       3/12     │  层标签条 (1 行)
├────────────┬─────────────────────────────────────────────────┤
│ 2024-03!B5 │ =L[-1]!B5 + C5 - D5                             │  地址框 + 公式栏 (1 行)
├────────────┴──────────────────────────────┬──────────────────┤
│      A         B         C        D       │ 深度 B5          │
│  1  科目     金额      收入     支出      │ ▸ 2024-01  1,200 │
│  2  ...                                   │   2024-02  1,450 │  网格 + 深度视图
│  5  余额    1,700                         │ ▸ 2024-03  1,700 │  (深度视图可关闭)
│                                           │   2024-04    ——  │
├───────────────────────────────────────────┴──────────────────┤
│ NAV  B5:D8×3层  和=12,340  均=1,028  数=12      * 未保存      │  状态栏 (1 行)
└──────────────────────────────────────────────────────────────┘
```

- **层标签条**:显示全部非隐藏层,当前层用 `[ ]` 与反色标出;放不下时左右两侧显示 `‹ ›`,
  当前层始终可见;右端显示 `当前序号/总层数`
- **地址框**:`层名!地址`,选区时显示 `层名!左上:右下`(跨层时追加 `×N层`)
- **公式栏**:导航模式显示 `input_text`,编辑模式显示编辑缓冲区与光标
- **网格**:行号列固定宽度(按最大行号自适应,4..=8),数据列默认宽 10
- **深度视图**:见 6.4;默认关闭
- **状态栏**:模式 + 选区描述 + 聚合统计(仅数值格)+ 未保存标记 + 最近一条消息

## 6.2 模式

```rust
pub enum Mode {
    /// 导航:移动光标、选区、执行命令
    Nav,
    /// 编辑:单元格内容编辑中(公式栏可见光标)
    Edit,
    /// 命令行:底部一行变成 `:` 输入行
    Command,
    /// 深度视图获得焦点
    Depth,
    /// 帮助浮层
    Help,
}
```

模式转换:

```
Nav ──可打印字符/F2/Enter──▶ Edit ──Enter/Tab/Esc──▶ Nav
Nav ──Ctrl+P──▶ Command ──Enter/Esc──▶ Nav
Nav ──F3──▶ Depth ──Esc──▶ Nav          (F3 在 Depth 模式下关闭面板)
Nav ──F1──▶ Help ──任意键──▶ Nav
```

**为什么命令行不用 `:` 打开:** 在电子表格里 `:` 是可打印字符,输入 `A1:B2` 是日常操作。
把 `:` 当模式切换键会让"输入区域引用"变得别扭。因此用 `Ctrl+P` 打开命令行,
命令行内部仍以 `:` 作为提示符(视觉上与 vim 一致)。

## 6.3 按键表

尽量与 Excel 保持一致 —— 用户的肌肉记忆比一致性理论更重要。

### 导航模式

| 按键 | 动作 |
|---|---|
| `←` `↑` `→` `↓` | 移动光标 |
| `Ctrl+←/↑/→/↓` | 跳到当前数据块边缘(Excel 行为) |
| `Home` / `Ctrl+Home` | 本行首列 / A1 |
| `End` / `Ctrl+End` | 本行末个非空格 / 已用区域右下角 |
| `PgUp` / `PgDn` | 上下翻一屏 |
| **`Ctrl+PgUp` / `Ctrl+PgDn`** | **上一层 / 下一层** |
| **`Alt+↑` / `Alt+↓`** | 同上(备用,给不支持 `Ctrl+PgUp` 的终端) |
| `Shift+方向` | 扩展选区(行列) |
| **`Ctrl+Shift+PgUp/PgDn`** | **沿层轴扩展选区**(形成长方体) |
| `Ctrl+A` | 全选当前层已用区域 |
| 可打印字符 | 进入编辑模式,清空原内容 |
| `F2` / `Enter` | 进入编辑模式,保留原内容 |
| `Delete` / `Backspace` | 清空选区 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴(程序内剪贴板,含长方体) |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做(深度 100) |
| `Ctrl+D` | **向下填充**(Excel 一致) |
| `Ctrl+R` | **向右填充**(Excel 一致) |
| **`Ctrl+L`** | **跨层填充** —— 把当前层选区填充到选中的其余层 |
| `F3` | 打开/关闭深度视图并聚焦 |
| `F1` | 帮助浮层 |
| `Ctrl+P` | 命令行 |
| `Ctrl+S` | 保存(等价 `:w`) |
| `Ctrl+Q` | 退出(有未保存改动时要求确认) |

`Ctrl+L` 是三维版的填充,是 `Ctrl+D`/`Ctrl+R` 在第三根轴上的自然延伸。
填充时的引用重写规则见 [03 §3.6](03-formula-language.md#36-复制与填充时的引用重写):
相对层引用 `L[k]!` 保持偏移不变,这正是"每层都算上一层的环比"能一次填出来的原因。

### 编辑模式

| 按键 | 动作 |
|---|---|
| `←` `→` `Home` `End` | 移动文本光标 |
| `Backspace` / `Delete` | 删除字符 |
| `Enter` / `Shift+Enter` | 提交并下移 / 上移 |
| `Tab` / `Shift+Tab` | 提交并右移 / 左移 |
| `Esc` | 放弃编辑,恢复原内容 |

提交时若公式解析失败:**停留在编辑模式**,状态栏红色显示
`解析错误(位置 7):期望 ')'`,内容不丢。这是 [02](02-data-model.md#用户输入的解释规则)
里"解析失败不写入"这条设计的收益所在。

MVP **不做** Excel 的"点选引用"(编辑公式时用方向键去点单元格自动插入引用)——
方向键在编辑模式里就是移动文本光标。

### 命令行模式

| 按键 | 动作 |
|---|---|
| 可打印字符 | 输入 |
| `Tab` | 补全命令名(仅命令名,不补全路径) |
| `↑` / `↓` | 历史记录 |
| `Enter` | 执行 |
| `Esc` | 取消 |

## 6.4 深度视图

**这是三维表格最有价值的交互。** 面板固定在右侧,宽度 20 列,纵向列出当前光标所在
`(row, col)` 位置在**所有层**中的值:

```
┌ 深度 B5 ──────────┐
│ ▸ 2024-01   1,200 │   ▸ 标记有公式的格
│   2024-02   1,450 │
│ ▸[2024-03]  1,700 │   [ ] 标记当前层,反色
│   2024-04      —— │   —— 表示空格
│ ▸ 2024-05  #REF!  │
└───────────────────┘
```

行为:

- 面板**始终跟随网格光标**:光标移到 C7,面板立刻变成 C7 沿层轴的切面
- 光标切层时,面板里的高亮行同步移动
- 层多于面板高度时,以当前层为中心滚动
- 底部显示这一列数值的 `和 / 均 / 数`,与状态栏的选区统计互补

聚焦后(`F3`)可以**原地编辑其它层的同位置单元格**:

| 按键(Depth 模式) | 动作 |
|---|---|
| `↑` / `↓` | 在层之间移动高亮(同时切换网格的当前层) |
| `Enter` / `F2` | 就地编辑高亮那一层的该单元格 |
| `Esc` | 回到导航模式(面板保持打开) |
| `F3` | 关闭面板并回到导航模式 |

就地编辑复用编辑模式的缓冲区与提交逻辑,只是渲染位置在面板里 ——
**不要写第二套编辑实现**。

## 6.5 命令

命令行里以 `:` 提示符开头。参数用空格分隔,路径含空格时用双引号包裹。

| 命令 | 说明 |
|---|---|
| `:w [路径]` | 保存 `.c3`;省略路径则用当前文件名,无当前文件名则报错 |
| `:e 路径` | 打开 `.c3`(有未保存改动时拒绝,`:e!` 强制) |
| `:q` / `:q!` | 退出 / 放弃改动退出 |
| `:wq` | 保存并退出 |
| `:layer add 名字` | 在末尾新建层 |
| `:layer ins 名字` | 在当前层之前插入 |
| `:layer del [名字]` | 删除层,省略则当前层;仅剩一层时报错 |
| `:layer rename 新名` | 重命名当前层 |
| `:layer move n` | 把当前层移到第 n 位(1-based) |
| `:layer dup 名字` | 复制当前层 |
| `:layer hide` / `:layer show 名字` | 隐藏 / 取消隐藏 |
| `:goto 引用` | 跳转,支持 `B5`、`Sales!B5`、`#3!B5` |
| `:import xlsx 路径` | 导入,**替换**当前工作簿;完成后显示导入报告摘要 |
| `:import csv 路径 [层名]` | 导入为新层 |
| `:export xlsx 路径` | 导出;完成后显示降级公式条数,可用 `:report` 查看明细 |
| `:export csv 路径` | 导出当前层 |
| `:report` | 显示最近一次导入/导出的完整报告(浮层) |
| `:fmt 规格` | 设置选区数字格式:`general` \| `fixed:2` \| `thousands:2` \| `pct:1` \| `cur:2:¥` \| `text` |
| `:align auto\|left\|center\|right` | 设置选区水平对齐 |
| `:bold on\|off` | 设置选区粗体 |
| `:width n` | 设置选中列宽(3..=60) |
| `:help` | 等价于 `F1` |

未知命令 ⇒ 状态栏提示 `未知命令:xxx(F1 查看帮助)`,不退出命令行。

## 6.6 渲染细节

**只渲染视口内的单元格。** 网格组件根据滚动偏移与可见行列数,对每个可见坐标调用
`Workbook::display_text` —— 绝不遍历整个 `SparseGrid`。

值的显示:

| 情况 | 显示 |
|---|---|
| 数字放得下 | 按 `NumberFormat` 格式化,右对齐 |
| 数字放不下 | `####`(填满列宽,Excel 行为) |
| 文本放不下 | 截断并以 `…` 结尾;**右边相邻格为空时允许溢出显示**(Excel 行为) |
| 错误值 | 显示错误字符串,居中 |
| 空格 | 空白 |

`Align::Auto` 的解析:数字右对齐,文本左对齐,布尔与错误居中。

**中日韩字符宽度:** 用 `unicode-width` 计算显示宽度,不要用 `chars().count()` ——
否则中文表头会把整列撑歪。这是 TUI 里最容易出的显示 bug。

**颜色**(用 ratatui 的默认 16 色,不假定终端支持真彩):

| 元素 | 样式 |
|---|---|
| 当前层标签 | 反色 |
| 光标格 | 反色 |
| 选区 | 暗色背景 |
| 公式格的值 | 默认色(不特殊标记,避免花哨)|
| 错误值 | 红色 |
| 状态栏错误消息 | 红色 |
| 深度视图中的当前层 | 反色 |

## 6.7 终端生命周期

- 启动:进入 alternate screen + raw mode,启用鼠标捕获(仅用于点击定位单元格与滚轮滚动)
- 退出:**必须**还原终端。用 RAII guard(`Drop` 里还原),并安装 panic hook
  在 panic 前还原 —— 否则一次崩溃会让用户的终端变成乱码
- 事件循环:阻塞式 `read()`,不做定时重绘;每次事件后重绘一次

## 6.8 验收

TUI 部分不做自动化端到端测试(成本远高于收益)。M8 的验收是**手工清单**,
逐条勾选,见 [08 §M8](08-acceptance-tests.md#m8-tui手工验收清单)。

可自动化测试的部分要单独抽出来测:

- `input.rs` 的按键 → `Action` 映射(纯函数,好测)
- `command.rs` 的命令行解析(纯函数,好测)
- 列宽/显示宽度计算(纯函数,含中文用例)

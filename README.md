# 文章可读性增强器 (Article Readability Formatter)

一个 Chrome 浏览器插件：一键调用大模型 API，为当前网页的长文章自动标注重点——
关键信息加粗、核心论点放大、次要信息缩小变淡、情绪明显的句子上色，让统一字号
的大段文字变得有层次、方便快速抓重点。

支持 **Anthropic（Claude）** 和 **DeepSeek** 两种服务商，可在设置页切换，两边的
Key 分开保存互不影响。

## 安装

1. 打开 `chrome://extensions`，右上角开启"开发者模式"。
2. 点击"加载已解压的扩展程序"，选择本仓库目录。
3. 点击插件图标 → 打开"设置" → 选择服务商（Anthropic 或 DeepSeek）→ 填写对应的
   API Key（以及可选的模型 ID，留空则用默认值：Anthropic 用
   `claude-sonnet-4-5-20250929`，DeepSeek 用 `deepseek-chat`）。

## 使用

打开任意一篇长文章网页，点击插件图标，点"格式化本页文章"。插件会：

1. 在页面里找到正文容器（优先 `<article>`，否则用启发式规则找文本最集中的区块）。
2. 把正文按段落分块（每块约 3000 字符）交给 Claude 分析。
3. Claude 只在原文基础上插入标注标签，不改变任何文字，返回后由插件做白名单
   清洗（只允许 `<b>` 和固定几个 class 的 `<span>`），再写回页面对应段落。

页面右下角会显示处理进度。

## 效果对照

- **关键信息**：`<b>` 加粗
- **全文最核心的论点**：放大加粗（`arf-hi`）
- **次要/背景信息**：缩小变淡（`arf-lo`）
- **情绪偏正面**：绿色（`arf-pos`）
- **情绪偏负面/警示**：红色（`arf-neg`）

## 隐私与费用

- API Key 只保存在浏览器本地存储（`chrome.storage.local`），仅用于你的浏览器
  直接请求所选服务商的 API（`api.anthropic.com` 或 `api.deepseek.com`），不会
  上传到任何其它服务器。
- 点击"格式化"后，当前页面的正文文本会被发送给所选服务商做分析，每次点击都会
  产生 API 调用费用，请留意用量。

## 已知限制

- 优先处理 `<p>` 标签；如果页面里 `<p>` 太少（常见于小红书这类用 `<div>`/`<span>`
  堆砌正文的 SPA 页面），会退化去找"内部没有块级子元素、本身有大段文字"的
  `<div>`/`<span>`/`<li>` 当作段落。这是启发式规则，未必对所有站点都准。
- 写回时会丢失原段落内部的行内格式（链接、斜体等），统一替换成纯文本 + 标注结果。
- 正文容器识别（找到"这是文章主体"这块区域）也是启发式规则，非典型排版的网页
  仍可能识别不准。
- 模型返回内容依赖 prompt 约束"不改变原文用词"，理论上仍可能出现措辞漂移；如
  发现明显跑偏，欢迎反馈。
